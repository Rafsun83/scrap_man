## 2. What "interactive" means to you

Pick the ones you want:

- [ ] Small animations: buttons that press in, cards that slide in, smooth screen changes
- [ ] Haptics: the phone vibrates on accept, on code entry, on payment done
- [ ] Gestures: swipe to accept a request, pull to refresh, swipe-up bottom sheets
- [ ] Animated states: a radar pulse while searching for a collector, a live moving collector pin on the map, a celebration when payment completes
- [ ] Illustrations or Lottie animations for empty, success and error states
- [ ] Skeleton loaders in place of spinners
